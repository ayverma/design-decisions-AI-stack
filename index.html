    Live Schema Editor

    Edit the JSON-LD schema block directly. Click Validate to check syntax, Apply to re-render UI from changes, Save As HTML to download a new standalone file with your edits baked in.

    How to add a new functionality
    1. New decision: add an object to "decisions" array. Fields: id, title, body, refs. Click Apply.
    2. New stack layer: add to "stackLayers". Fields: id, label, options (array of strings).
    3. New tunable slider: add to "tunables". Fields: id, label, min, max, step, default, desc.
    4. Rename project: edit project.name and project.purpose. Header + localStorage key auto-update.
    5. Add a totally new section type (e.g. risk register, milestones): requires a JS render function. Add the array under a new top-level key in JSON, then ask an AI to wire it up — "extend the renderer to render a 'risks' array as a table". UI auto-rebuilds on Apply.
    Save-As-HTML — what it does

    Generates a new HTML file where the JSON-LD block contains your edited schema, and the localStorage key is renamed so the new file starts with fresh state. Use this to fork the doc for a different project, share read-only snapshots, or version-control a baseline.

    For AI Chatbots — Compact Context

    How AI Context Stays Small
    
      
    The JSON-LD block at the top of this file is the single source of truth. The HTML/CSS/JS just renders it. When you ask an AI assistant a question about this design, paste only the JSON-LD block (or the markdown summary) — not the whole HTML — and you save 70%+ of context tokens.
    
      
    Round trip: AI proposes changes to the schema (JSON delta) → you paste back into the <script id="design-schema"> block → reload → UI reflects new schema.
